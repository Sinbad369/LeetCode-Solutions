# 🚀 Data Structures & Algorithms (DSA) — Google 2027 Journey

Welcome! This repository documents my journey mastering Data Structures and Algorithms from scratch using Java, with the long-term goal of cracking technical interviews at **Google** and top tech companies.

Instead of just saving raw solutions, I document my **thought process, brute force attempts, time/space complexity trade-offs, and edge cases** inside each file.

---

## 📌 My Learning Methodology

I believe in building real intuition rather than memorizing solutions. For every problem in this repository, I follow a strict execution loop:

1. **Understand the Mechanics:** Break down the core algorithmic pattern (Arrays, Hashing, Two Pointers, etc.) and analyze the problem constraints.
2. **First-Principles Coding:** Implement the logic in standard Java without relying on IDE autocompletion or visual hints.
3. **Complexity Analysis:** Explicitly document Time $\mathcal{O}(...)$ and Space $\mathcal{O}(...)$ complexities for Brute Force, Better, and Optimal approaches inside the source code comments.
4. **Dry Run & Verification:** Trace execution line-by-line with edge cases (`null` inputs, array lengths $< 2$, boundary limits) to act as my own compiler.
